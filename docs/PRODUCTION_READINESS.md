# Production Readiness — Ma Yai On POS

สถานะเอกสารนี้อิงจากซอร์สโค้ดและผล CI ที่ระบุชัดเจนเท่านั้น ไม่ใช่ผลทดสอบบนโทรศัพท์จริง

## ขอบเขตปัจจุบัน

- ระบบ Android backup ถูกปิดด้วย `android:allowBackup="false"`; ไฟล์กฎ backup และโฟลว์ cloud restore ถูกนำออกแล้ว
- แอปยังคงใช้ SQLite `data_hub.db` / `hub_records` เป็นแหล่งข้อมูลในเครื่อง และซิงก์รายการที่รอไปยัง Cloud เมื่อเงื่อนไขพร้อม
- การซิงก์ยังใช้ Firestore path เดิม `dataHubBackups/{storeId}/records/{recordId}` เพื่อรักษาความเข้ากันได้กับ Security Rules และ Cloud Functions ที่มีอยู่ ชื่อ path นี้เป็นสัญญาเก่าของระบบจัดเก็บ ไม่ใช่ฟังก์ชันสำรอง/กู้คืนที่ผู้ใช้เรียกใช้ได้
- ระบบขายและชำระหนี้บางส่วนใช้ธุรกรรมฝั่งเซิร์ฟเวอร์และต้องทดสอบกับ Firebase project ที่ deploy จริง
- เครื่องพิมพ์บาร์โค้ดและใบเสร็จยังไม่พัฒนาในรอบนี้ตามคำสั่งเจ้าของโปรเจกต์

## ข้อจำกัดที่ต้องทราบ

- การติดตั้งใหม่หรือย้ายไปโทรศัพท์เครื่องใหม่จะไม่ดาวน์โหลดข้อมูลเดิมจาก Cloud โดยอัตโนมัติ เพราะระบบ restore ถูกตัดออกแล้ว ห้ามรับรองการย้ายเครื่องหรือกู้คืนข้อมูลจนกว่าจะมีขอบเขตใหม่ที่ได้รับอนุมัติ
- การมี `google-services.json` หรือการ Build APK ผ่าน ไม่ได้ยืนยันว่า Firestore Rules, owner mapping หรือสิทธิ์เครื่องที่ deploy อยู่ถูกต้อง
- การ Build สำเร็จไม่เท่ากับติดตั้งสำเร็จหรือทดสอบบนอุปกรณ์จริง
- ห้ามเปลี่ยนชื่อฐานข้อมูลหรือทำ Schema Migration แบบลบข้อมูลเดิมโดยไม่มีแผน migration ที่ตรวจสอบแล้ว

## ตารางสถานะที่ต้องตรวจ

| ระบบ | สถานะจากซอร์สโค้ด | สิ่งที่ยังต้องยืนยัน |
|---|---|---|
| Local SQLite | มี `data_hub.db` และ `hub_records`; upgrade ปัจจุบันไม่ลบข้อมูล | ทดสอบ CRUD ของทุกหน้าจอและ migration |
| Cloud sync | มีสถานะ pending/failed และ WorkManager retry | ทดสอบ offline, process restart, timeout, retry, 500+ records และ idempotency |
| Owner / device access | มี Firebase email verification, owner mapping และ active-device checks ในโค้ด | ทดสอบกับ Firebase project และ Security Rules ที่ deploy จริง |
| Server sales / debt payment | มีเส้นทางธุรกรรมฝั่งเซิร์ฟเวอร์ | ทดสอบผลลัพธ์จริง การตอบกลับสูญหาย และการกดซ้ำ |
| Backup / restore | ปิดและนำโฟลว์ในแอปออกแล้ว | ไม่อยู่ในขอบเขตปัจจุบัน; ห้ามอ้างว่ารองรับการย้ายเครื่อง |
| Barcode printer / receipt printer | เว้นไว้ตามคำสั่ง | ยังไม่ทดสอบและยังไม่รายงานว่ารองรับ |
| APK Build | ต้องอ้างอิงผล Actions ของ commit ล่าสุดเท่านั้น | Build ปัจจุบัน, ดาวน์โหลด artifact และติดตั้งจริง |

## Acceptance checklist ก่อนใช้งานจริง

- [ ] GitHub Actions Build APK ผ่านบน commit ล่าสุดของชุดรวม
- [ ] Firebase Functions และ Firestore Rules tests ผ่านบน commit เดียวกัน
- [ ] ติดตั้งและเปิดแอปบน Android จริง
- [ ] ทดสอบสร้างบาร์โค้ดและค้นหาคลังบาร์โค้ด โดยไม่เปลี่ยนสต๊อกจากเมนูบาร์โค้ด
- [ ] ทดสอบรับสินค้าและตรวจนับสต๊อกว่าให้ผลต่างกันตามข้อกำหนด
- [ ] ทดสอบแก้ราคาและตรวจประวัติราคา
- [ ] ทดสอบขายเงินสด/ขายเชื่อ การชำระหนี้ และป้องกันการบันทึกซ้ำ
- [ ] ทดสอบออฟไลน์และการซิงก์กลับออนไลน์ โดยตรวจข้อมูลในเครื่องและผลตอบกลับจากเซิร์ฟเวอร์
- [ ] ตรวจสอบ owner mapping และ Security Rules ที่ deploy จริง
- [ ] ไม่ทดสอบหรืออ้างความสำเร็จของเครื่องพิมพ์ เพราะยังอยู่นอกขอบเขต

จนกว่ารายการที่เกี่ยวข้องจะมีหลักฐานจริง ห้ามรายงานว่าแอปพร้อมใช้งาน production 100%
