# นโยบายเก็บรักษาข้อมูลอัตโนมัติ — ร้านแม่ใหญ่อ่อน POS

เอกสารนี้เป็นนโยบายของระบบ Retention สำหรับข้อมูลใน `hub_records` ที่ผูกกับรหัสร้านค้า โดยเริ่มใช้เมื่อแอปที่มีโค้ดนโยบายนี้ถูกติดตั้งและ WorkManager ได้ทำงานสำเร็จ

## ประเภทข้อมูลที่ลบอัตโนมัติได้

| dataType | อายุเก็บ | เงื่อนไขเพิ่มเติม |
|---|---|---|
| `sale_bill` | 30 วันนับจากวันที่ชำระครบ | ต้องมีสถานะ `จ่ายแล้ว`, ยอดคงเหลือไม่เกิน 0.009 บาท, มี `sale_history` ที่เก็บ snapshot ของบิลตรงกัน และ snapshot นั้นซิงก์สำเร็จแล้ว |
| `sale_history` | 1 ปีนับจาก `createdAt` | ต้องซิงก์สำเร็จและ revision ยังตรงกับรายการที่ตรวจสอบก่อนลบ |
| `price_history` | 6 เดือนนับจาก `changedAt` | ต้องซิงก์สำเร็จและ revision ยังตรงกับรายการที่ตรวจสอบก่อนลบ |

## ประเภทข้อมูลที่เก็บไว้ ไม่ลบอัตโนมัติ

ข้อมูลต่อไปนี้เป็นข้อมูลหลัก บัญชี หรือหลักฐานทางธุรกิจ จึงไม่ลบโดยอัตโนมัติในนโยบายรุ่นนี้:

- `product` — สินค้าและยอดสต็อกปัจจุบัน
- `stock_history` — บัญชีเคลื่อนไหวสต็อกและประวัติรับเข้า/ขาย/ตรวจนับ
- `receipt` — ใบเสร็จและข้อมูลสำหรับพิมพ์ซ้ำ
- `credit_payment` — รายการรับชำระหนี้
- `credit_payment_history` — ประวัติและการจัดสรรเงินชำระหนี้ให้แต่ละบิล
- `credit_customer` — ข้อมูลลูกหนี้
- `barcode_item` — ข้อมูล Barcode
- `app_notification` และประเภทแจ้งเตือนอื่น — เก็บไว้จนกว่าจะมีนโยบายแยกที่ผ่านการทบทวน
- ประเภทข้อมูลที่ไม่รู้จักหรือเพิ่มในอนาคต — เก็บไว้โดยปริยายจนกว่าจะกำหนดนโยบายชัดเจน

## การป้องกันข้อมูล

1. ไม่ลบบิลที่ค้างชำระหรือมียอดคงเหลือมากกว่า 0.009 บาท
2. ไม่ลบรายการที่ยังไม่ซิงก์สำเร็จ หรือมีประเภทข้อมูลไม่ตรงกับที่อนุญาต
3. สำหรับบิลขาย ต้องมี snapshot ในประวัติการขายที่ซิงก์สำเร็จก่อน
4. ตรวจ revision ก่อนลบ และลบข้อมูลในเครื่องเฉพาะเมื่อ Cloud ลบสำเร็จและ revision ในเครื่องยังตรงกัน
5. หากการลบรายการใดล้มเหลวหรือหมดเวลารอ ให้ถือว่ารอบนั้นล้มเหลวและลองใหม่ภายหลัง
6. ระบบทำงานเป็นงานเบื้องหลังรายวันผ่าน WorkManager เมื่อมีเครือข่าย การทำงานจริงอาจล่าช้าตามข้อจำกัดของ Android
7. นโยบายนี้ไม่ใช่การสำรองข้อมูล และไม่รับประกันว่าจะกู้คืนข้อมูลที่ลบไปแล้วได้ หาก Cloud ลบสำเร็จ

## ข้อจำกัดที่ต้องทราบ

- การลบอัตโนมัติจะเริ่มทำงานหลังติดตั้งแอปเวอร์ชันที่มีนโยบายนี้ และเมื่อ WorkManager ทำงานได้ ไม่ใช่การลบย้อนหลังทันที ณ เวลาที่ Commit
- ก่อนใช้งานกับข้อมูลร้านจริง ควรทดสอบกับข้อมูลจำลองและตรวจการกู้คืน/ซิงก์ก่อน
- ระยะเวลาเก็บรักษานี้เป็นนโยบายผลิตภัณฑ์ ไม่ใช่คำแนะนำทางกฎหมายหรือภาษี หากต้องเก็บเอกสารทางบัญชีตามข้อกำหนดเฉพาะ ควรปรับระยะเวลาให้สอดคล้องก่อนเปิดใช้กับร้านจริง
